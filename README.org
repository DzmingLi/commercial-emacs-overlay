#+title: window-border-mode

Native selected-window borders for GNU Emacs 31 PGTK, ported from
[[https://github.com/commercial-emacs/commercial-emacs][Commercial Emacs]]. The border is part of Emacs redisplay and window
geometry, with a Cairo renderer for PGTK.

* Use
Build Emacs with this repository's patch, then enable the built-in mode:

#+begin_src emacs-lisp
(require 'window-border)
(setq window-border-width 2)
(window-border-mode 1)
#+end_src

Customize the =window-border= face to change its color. Disable the mode
with =(window-border-mode -1)= to restore normal geometry. Minibuffer,
pseudo windows and terminal frames reserve no border. The mode can be
enabled during daemon startup.

This feature requires changes to Emacs's C redisplay code. A patched
Emacs binary is required; copying its Lisp file into another Emacs does
not install the feature. PGTK is the supported and tested graphical port.

* Nix overlay
This flake exports =overlays.default= and a named editor,
=emacs31-pgtk-window-border=:

#+begin_src nix
inputs.window-border-mode.url = "github:DzmingLi/window-border-mode";

# In a module receiving pkgs and inputs:
let
  borderPkgs = pkgs.extend inputs.window-border-mode.overlays.default;
  editor = borderPkgs.emacs31-pgtk-window-border;
  epkgs = pkgs.emacsPackagesFor editor;
in
  epkgs.emacsWithPackages (epkgs: [ /* your packages */ ])
#+end_src

For Home Manager, assign the editor or its wrapped result to
=programs.emacs.package=. Use =emacsPackagesFor= with that same editor for
its Lisp and native packages. Restart Emacs after activating a new binary.

The overlay adds only =patches/gnu-emacs31-window-border.patch= to the
base editor. It targets GNU Emacs 31. The repository contains the patch,
its regressions, this documentation and upstream/license information.

* Tests
Use the patched editor to run batch regressions:

#+begin_src sh
make check EMACS=/path/to/patched/emacs
#+end_src

For graphical geometry checks, run a separate disposable PGTK process:

#+begin_src sh
/path/to/patched/emacs -Q \
  -l tests/window-border-test.el \
  --eval '(let ((noninteractive t)) (ert-run-tests-batch-and-exit))'
#+end_src

The suite checks width validation, terminal/minibuffer geometry, space
reservation and restoration, nested splits, scrolling and resizing. GUI
checks skip terminal frames. Inspect Cairo painting visually when changing
the renderer, especially after switching windows or resizing them. The GUI
test command exits its own Emacs process.
